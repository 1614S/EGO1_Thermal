# EGO1 芯片结温感知与动态热管理演示系统 —— v0.3（含虚拟热台）

基于 EGO1（**XC7A35T-1LCSG324I**）的闭环热管理演示工程：
XADC 结温 + AM2301 外部温湿度 → 统一采集 → 滤波/标定 → PI+前馈 控风扇 → MMCM DRP 五档调频 → UART 遥测。

## v0.3：没有热学实验室也能跑完整演示

`rtl/vplant/` 新增一套**虚拟热台**，只在**器件接口层**替换 XADC（DRP）与 AM2301（1-Wire），
中间的算法/控制/遥测 RTL 一行不改。`sw6=1` 用虚拟热台，`sw6=0` 用真实器件。

| 模块 | 非理想性（都是"真风扇/真芯片"会有的毛病） |
|---|---|
| `thermal_core` | 2R2C 双节点（结/壳分离），µK 整数定点，三级流水 |
| `fan_vplant` | 6 % 死区+迟滞、16 点非线性调速、200 ms 启动延迟、256 ms 惯性、±32 rpm 抖动、±8 % 个体差异、真 tach |
| `xadc_vplant` | 增益 0.998 + 偏置 +1.8 ℃ + 噪声 + 12 bit 量化（UG480 量级） |
| `am2301_vplant` | 真 40 bit 1-Wire 时序应答 + 校验和 + 每 N 帧注入校验错 |
| `ambient_vplant` | 随机慢漂 + 空调阶跃 ±4 ℃ 随时触发 |

### 关键设计决策（报告里的加分点）

1. **执行器线性化**：风扇 0–6 % 不转，PI 输出直接给会出现 16 ℃ 不可控空档
   → `duty_fan = 60 + u×940/1024`。
2. **1/R2 对流量连续**：原来 9 点查表在低转速段一档 8 ℃，PI 压不住 ±1 ℃
   → 改为 `1/R = 1/34 + (1/8−1/34)·flow/256`。
3. **前馈治超调**：`u_ff = 1528 − 40·(Tset−Tamb)`，PI 只修残差；积分允许取负。
4. **自动 DVFS 外环**（`rtl/ctrl/gear_ctrl.v`，`sw5=1` 启用）：风扇吹不动
   （占空比 >95 % 且超设定 1 ℃）持续 5 s → 自动降一档；有余量 10 s → 升档。

## 历史版本

v0.2 更新：
- **AM2301 已修复**：根因不是位对齐，而是 `400×6554` 被 16 bit 上下文截断；改成 32 bit 乘法后读数正确（40.0 ℃ / 55.0 %RH）。
- **引脚已按官方 `EGo1.xdc` 填好**（`constr/ego1_pins.xdc`）。
- **PI 乘法/符号宽度修复**：`p_c + i_c[31:16]` 曾因无符号扩展导致占空比误判，现在闭环稳态误差 0.6 ℃。
- **综合分支已通过 elaboration**（MMCME2_ADV / XADC / BUFG 原语 + glbl），不再是"只会在仿真里跑"。

## 引脚映射（摘自官方 EGo1.xdc）

| 信号 | 引脚 |
|---|---|
| clk / rst_btn | P17 / P15 |
| btn[4:0] | R11 R17 R15 V1 U4（按下为低，顶层已取反） |
| sw[7:0] | P5 P4 P3 P2 R2 M4 N4 R1 |
| led[15:0] | F6 G4 G3 J4 H4 J3 J2 K2 K1 H6 H5 J5 K6 L1 M1 K3 |
| seg[7:0]（0 组段选） | B4 A4 A3 B1 A1 B3 B2 D5 |
| an[3:0]（0 组位选） | G2 C2 C1 H1 |
| uart_rx / uart_tx | N5 / T4 |
| fan_pwm / fan_tach / dht_dq | B16 / A15 / A13（Pmod exp_io0/1/2） |

> 数码管只用了 0 组（4 位）；若上板发现段码顺序或共阳/共阴极性不符，改 `seg7_scan` 的译码表或 XDC 里的位序即可。

## 已知问题 / 下一步

1. ~~PI 超调 15 %~~ → **已解决**：加前馈 + 执行器线性化 + 1/R 连续化，三档超调 8.2/3.4/9.4 %。
2. **待补模块**：`fan_tach`（4 线风扇测速与堵转判定）、`acq_fifo`、`dbg_mux`、ILA 约束。`cmd_proc` 已完成（见上）。
3. **XADC 只读了温度通道**：VCCINT/VCCAUX 没接入，功耗目前是模型（`p_est`）。
   报告里必须声明这一点，否则热阻 θ 的"实测"站不住。
4. **DRP 切档仍未在真实器件上验证**：寄存器编码按 Clocking Wizard 模板推导，
   但本机没有 Artix-7 库、也无法用 unisims 让 MMCM 锁定（见 `sim/tb/tb_drp_wave.sv` 文件头）。
   首次上板务必先读 `F_MEAS`（0x17）确认 4 档 = 1500。
5. **两点标定流程还没有**：`calib` 的增益/偏置寄存器在，但没有"在两点上采样然后算 a/b"的
   状态机或命令 —— 需要 `cmd_proc` 配合。
6. **时序/资源是代跑器件数据**：`xc7z020clg400-1`，不是 35T。

```bat

```

结果：`PASS=15 FAIL=0`。每个 TB 用 `-s <top>` 单独 elaborate，失败只标那一项，
联调时"哪个模块坏了"一望即知。

**新增的 RTL**（`rtl/vplant/`，6 个文件）：

| 文件 | 作用 | 关键非理想性 |
|---|---|---|
| `vplant_pkg.vh` | 物理参数唯一事实源 | 单位全为整数（µK / mW / mK·mW⁻¹ / nJ） |
| `thermal_core.v` | 2R2C 双节点热网络 | 结/壳分离，三级流水，整数定点 |
| `fan_vplant.v` | 虚拟风扇 | 6 % 死区+迟滞、16 点非线性调速、200 ms 启动延迟、256 ms 惯性、±32 rpm 抖动、±8 % 个体差异（转速输出仅模型自用，控制器已不测速） |
| `xadc_vplant.v` | 虚拟 XADC（DRP 从机） | 增益 0.998 + 偏置 +1.8 ℃ + 噪声 + 12 bit 量化（UG480 量级） |
| `am2301_vplant.v` | 虚拟 AM2302（1-Wire 从机） | 真 40 bit 时序应答 + 校验和 + 每 N 帧注入校验错 |
| `ambient_vplant.v` | 环境温度 | 随机游走慢漂 + 空调阶跃 ±4 ℃ 可随时触发 |

**整定的三个根因**（写进报告 §5"参数整定过程"能拿分，详见 `.work/03_整定记录.md`）：

1. 风扇 0–6 % 死区在闭环里造出 **16 ℃ 的不可控空档** → 控制器必须做最小占空比映射
2. `rpm→R2` 用 9 点查表，低转速段一档 = 8 ℃ → 改成 **1/R 对流量线性**（h∝v），连续无台阶
3. 冷态起跳时积分要从 0 爬到 90 %，爬的过程温度已冲过头 → 加**前馈** + **允许负积分**

最终 Kp = 200 duty/℃、Ki = 1.0 duty/(℃·样本)、前馈 `u_ff = 1528 − 40·ΔT`。

**给报告的直接素材**：`.work/03_整定记录.md`（整定表）、`.work/01_基线复现.md`（基线复现）、
`.work/04_进度汇报.md`（指标对照）。这三份是工作记录，**要入库需 `git add -f` 或移到 `docs/`**。

> ✅ 已核对：`am2301_ctrl.v` 的 `PERIOD_US` 参数硬件模式取 **2 000 000 µs**，与手册要求的 ≥2 s 转换间隔一致；

## 附录 A：报告里必须出现的公式清单

1. XADC 温度：`T(℃) = code × 503.975 / 4096 − 273.15`；定点 `T_q8_8 = code×63/2 − 69926`
2. AM2302：`T = raw16 × 0.1`；`RH = raw16 × 0.1`
3. 标定：`T_cal = a·T_raw + b`，`a = (T2−T1)/(x2−x1)`，`b = T1 − a·x1`
4. 一阶 IIR：`y[n] = y[n−1] + (x[n] − y[n−1])/4`，`τ ≈ 4·Ts = 0.4 s`
5. 热响应：`T(t) = T∞ − (T∞−T0)·exp(−(t−t0)/τ)`
6. 热阻：`θ = ΔT/P`，`u(θ)/θ = √((u(ΔT)/ΔT)² + (u(P)/P)²)`
7. 采样周期约束：`T_AM2302(2 s) ≫ T_sample(100 ms)` → 双源异步刷新 + 龄期标志

# 风扇接线与摆放指南（EGo1 板卡 + 12 V 4 线风扇）

> 交给外部顾问/AI 的背景与操作说明。现场条件：**一块 EGo1 FPGA 板 + 一个 12 V 4 线风扇**，
> 没有热学实验室，没有示波器/逻辑分析仪（有万用表更好）。
> 目标：把风扇接到板子上，让 FPGA 用 PWM 控制转速、读回转速，形成"芯片发热→测温→吹风降温"的闭环。

---

# 一、这个系统在干什么（理解电路前先看懂这个）

```
   ┌──────────────────────────────────────────────────────────┐
   │  FPGA 芯片（XC7A35T）自己发热（内部跑自热负载，实测 950 mW） │
   └───────────────────────┬──────────────────────────────────┘
                           ↓
              片内 XADC 温度传感器（0.123 ℃/LSB，测自己的结温）
                           ↓
                    控制器（PI + 前馈）
                           ↓
              PWM 24.414 kHz ──→ 这里要接的 4 线风扇
                           ↓
                    风吹芯片 → 结温下降
                           ↑                        ↓
                           └──── 风扇转速反馈 ───────┘
```

**关键点：不需要加热片。芯片自己就是热源。**
外接的东西只有一个风扇（可选再加一个环境温湿度传感器，本次不涉及）。

# 二、板卡关键事实（接线前必须知道）

| 项 | 值 |
|---|---|
| 板卡型号 | EGo1 V2.2（E-Elements 依元素） |
| FPGA | Xilinx Artix-7 **XC7A35T-1CSG324C** |
| IO 电平 | **全部 3.3 V LVCMOS** |
| 板载时钟 | 100 MHz（P17） |
| 串口 | 同一根 USB 线虚拟 UART，**115200 8N1** |
| 板上电源 | **J10 只有 3V3 / 5V0 / GND，没有 12 V** |

> ⚠️ **板子没有 12 V 输出。** 风扇必须用外部 12 V 电源（实验室可调电源或 12 V 适配器）。
> **12 V 绝对不允许加到板子的任何引脚上**，会烧 FPGA。

---

# 三、风扇（4 线，12 V）

标准 4 线风扇的 4 根线：

| 线色 | 名称 | 作用 | 是否需要接 |
|---|---|---|---|
| 黑 | GND | 电源负极 | ✅ |
| 黄 | +12 V | 电源正极 | ✅ |
| **蓝** | **PWM 输入** | 调速信号（风扇内部自己斩波） | ✅ |
| **绿** | **TACH** | 转速反馈（开漏输出，每转 2 个脉冲） | ✅ |

> 如果买的是带 ARGB 灯效的版本，还会多出一根 **3-pin 的 5 V ARGB 线**（5V/Data/GND）：
> **这根线绝对不接任何东西**，用绝缘胶布把插头包住悬空。接错会烧板。

### 两个必须知道的行为

1. **蓝色 PWM 线悬空时 = 风扇全速**。因为风扇内部对 PWM 输入有一个上拉，悬空等于 100 % 占空比。
   所以"不接蓝线"的效果是"一直全速"，不是"停转"。
2. **绿色 TACH 线是开漏输出**，板上没有内置上拉，**必须外接一个 4.7 kΩ 电阻拉到 3.3 V**，
   否则读到的是恒 0（转速永远测不到）。

# 四、接哪几个脚（这是全文最关键的部分）

## 4.1 目标：板上 2×18 扩展排针 J5

板子边缘有一排 **2×18 = 32 针**的排针，丝印 `J5`（通用扩展 I/O）。
**这 32 个脚全是 IO，没有 GND、也没有电源。**

本项目用到其中 3 个脚：

| J5 脚号 | 板上丝印 | FPGA 引脚 | 本设计的用途 | 信号方向 |
|---|---|---|---|---|
| **1** | AD2P_15 | **B16** | **风扇 PWM 输出** | FPGA → 风扇（蓝线） |
| 2 | AD2N_15 | B17 | 未用 | — |
| **3** | AD10P_15 | **A15** | **风扇转速输入** | 风扇 → FPGA（绿线） |
| 4 | AD10N_15 | A16 | 未用 | — |
| 5 | AD3P_15 | A13 | （预留：AM2302 数据线） | 本项目不用 |
| 6 | AD3N_15 | A14 | 未用 | — |

其余 7–32 脚全部未用。

## 4.2 怎么找到第 1 脚

三种办法，任选其一（**接之前务必确认**）：

1. **看丝印**：J5 每根脚旁边都印了信号名，找 `AD2P_15`（第 1 脚）、`AD10P_15`（第 3 脚）
2. **看方形焊盘**：排针的第 1 脚通常是方形焊盘（其余是圆形）
3. **看丝印三角**：有些板子会在第 1 脚旁印一个小三角

> 一般 2×18 排针的编号方式：**一列是奇数（1,3,5…17），另一列是偶数（2,4,6…18）**，
> 第 1 脚和它旁边的脚（第 2 脚）构成一对。所以第 1、3、5 脚在**同一列**上，隔一个脚取一个。

## 4.3 电源与地从哪里取

| 需要 | 从哪里取 |
|---|---|
| 风扇 12 V | **外部 12 V 电源**（板子没有） |
| 风扇 GND | 外部电源负极 |
| **共地** | 外部电源负极 **必须**再用一根线连到板子的 GND |
| 上拉电阻的 3.3 V | 板上 **J10 的 3V3 脚**（或任何标 3V3 的排针/测试点） |
| 板子的 GND | J10 的 GND 脚，或 DAC 接口 J2 旁边的 GND 焊盘 |

# 五、完整接线图

```
        ┌─────────────────────┐
        │  外部 12V 电源       │   电压 12 V，限流先设 0.3 A
        │  （实验室可调电源）   │
        └──┬───────────────┬──┘
      正极 │            负极 │
           │                 ├──────────────┐
           │                 │              │
           │            ┌────┴────┐         │
           │            │ 风扇黑线 │         │
           │            │  (GND)  │         │
           │            └─────────┘         │
           │                                │
           │                          ┌─────┴──────┐
           │                          │ FPGA 板 GND │  ← 共地，必须
           │                          └────────────┘
           │
      ┌────┴─────┐
      │ 风扇黄线  │
      │  (+12V)  │
      └──────────┘

   ┌──────────┐
   │ 风扇蓝线  │───────► FPGA B16（J5 第 1 脚）
   │  (PWM)   │
   └──────────┘

   ┌──────────┐        ┌─────────────────┐
   │ 风扇绿线  │────────┤ 4.7 kΩ 电阻 ──── 板上 3V3
   │  (TACH)  │        └─────────────────┘
   └────┬─────┘
        └──────────────► FPGA A15（J5 第 3 脚）

   ┌──────────────┐
   │ ARGB 3pin 灯线│──── 绝缘胶布包住，悬空不接
   └──────────────┘
```

**一句话记法：**
- **12 V 只去风扇，不进板子**
- **GND 三方共地**（电源、风扇、板子）
- **蓝线 → B16**，**绿线 → A15 + 4.7 kΩ 上拉到 3.3 V**

# 六、接线顺序（分三步，每步都能单独验证，不会烧板）

## 第 1 步：风扇单独通电

只接电源和风扇，**不接板子**：

```
电源 12V 正极 → 风扇黄线
电源 负极     → 风扇黑线
```

- 电源限流设 **0.3 A**，电压 **12 V**
- **验证**：风扇应该**全速转**（蓝线悬空 = 100 % 占空比，属正常）

❌ 如果不转：正负极反了，或风扇坏。**先解决这一步再往下**。

## 第 2 步：共地

把 **电源负极** 和 **板子的 GND** 用一根线连起来。

- **验证**：万用表通断档，量「电源负极」和「板子 GND」应该导通（蜂鸣）

❌ 不共地 → 后面 PWM 和测速信号都没有共同参考，读数会乱跳。

## 第 3 步：接两根信号线

- 风扇**蓝线** → **B16（J5 第 1 脚）**
- 风扇**绿线** → **A15（J5 第 3 脚）**，并且绿线上再引一根线，串 **4.7 kΩ 电阻** 到**板上 3V3**

- **验证**：不用万用表也能验，见第八节（用软件看）

> **上拉电阻没有 4.7 kΩ 怎么办**：1 kΩ ~ 10 kΩ 的任意电阻都能用（这是慢速开漏信号，不挑阻值）。
> 实在一个电阻都没有，可以让 FPGA 内部上拉（需要重新生成比特流），但那是最后手段。

# 七、风扇怎么摆

```
              ┌───────────────┐
              │   风扇（正叶）  │
              │   风  ↓  ↓  ↓  │
              └───────────────┘
                     ↓
              距离 5 ~ 10 cm
                     ↓
        ┌────────────────────────┐
        │   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   │
        │   ▓  U1: XC7A35T   ▓  │  ← 板子正中那颗方形芯片（约 2 cm 见方）
        │   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓   │
        └────────────────────────┘
                  板子本体
```

| 要点 | 说明 |
|---|---|
| **对准** | 对着 **U1** 那颗芯片（丝印 `XILINX ARTIX-7 XC7A35T`，板子正中） |
| **距离** | **5–10 cm**。太近会挡风、还会把振动传给板子；太远风散掉 |
| **朝向** | 买的如果是**正叶**，风从"扇叶面"吹向"扇框面" → **扇框那一面朝芯片** |
| **固定** | 扎带 / 双面胶粘在桌面 / 小支架 / 夹子都行。**绝对不要让风扇的金属框直接压在板子上**（短路风险） |
| **不要挡风** | 风扇和芯片之间不要有东西（线材、手、纸） |

> 判断正叶/反叶：把风扇拿起来，扇叶那面朝向自己，看叶片弧度——
> 叶片往后兜（看不见凹面）= 正叶，风朝远离你的方向吹。

# 八、接好后怎么验证（软件，不需要仪器）

板子通过 USB 连电脑，串口 **115200 8N1**。有现成脚本：

```powershell
scripts\capture.bat -Port COM4 -Seconds 20
```

输出是一行一行的遥测帧，形如：

```
T= 42.32℃  Tset=50.0  TEXT=0.00  RH=0.0%  duty=0  gear=3  f=99.9MHz  P=950mW  state=0
```

| 字段 | 含义 | 接线成功后会看到 |
|---|---|---|
| `T` | 芯片结温 | 风扇吹起来后下降 |
| `duty` | PWM 占空比 0–1000 | 温度高于设定值时升高 |
| `rpm`/`fail_cnt` | 转速 / 堵转计数 | 转速跟 duty 走；拔风扇则 fail 计数增加、LED7 亮 |
| `state` | 0 正常 / 1 警告 / 2 过温 / 3 严重 | 正常应为 0 |

## 三级验证

**级别 1：风扇受控**
拨板上开关**全部到 ON**（虚拟热台模式），系统稳定在 50 ℃ 后采 20 秒。
发命令 `S=45.0` 把设定值调低 → `duty` 升高 → **风扇明显变快** ✅

**级别 2：测速通**
`rpm` 跟着 `duty` 变；拔掉风扇 → LED7 亮、`fail_cnt` 增加 ✅

**级别 3：物理闭环（最重要）**
把**丝印 SW1**（从右数第 2 个拨码开关）拨 OFF，切到真实温度模式，然后：

```powershell
scripts\board_step.bat -Port COM4 -StepTo 45.0 -PreSeconds 20 -PostSeconds 70
```

**判据**：`duty` 升高时 `T` 明显下降（预期降 3–8 ℃）→ **物理闭环成立** ✅

# 九、排错表

| 现象 | 最可能的原因 | 怎么办 |
|---|---|---|
风扇完全不转，`duty` 却在变 | ① 没共地 ② 蓝线没接（应该全速） ③ 电源没开 | 回到第 1、2 步重验 |
风扇一直全速，不受控 | ① 蓝线没接到 B16 ② 3.3 V 驱不动它 | 先量蓝线电压是否随 duty 变；不变就是电平问题 |
`rpm` 恒为 0 | tach 没上拉 | 加 4.7 kΩ 到 3.3 V |
转速读数差一倍 | 风扇不是 2 脉冲/转 | 需改代码里的系数 |
板子突然重启 | 风扇从板子取电了 | 必须用独立 12 V 电源 |
风扇有啸叫/抖动 | 蓝线接了但 PWM 频率不对 | 本设计是 24.414 kHz，在推荐区间，正常不该啸叫 |
接上灯线后板子死机 | ARGB 线接错了 | 立即断电，ARGB 线必须悬空 |

# 十、安全红线（贴墙上的那种）

1. **12 V 绝不接触板子任何引脚**。只去风扇。
2. **接之前先断电**，接完检查一遍再上电。
3. **ARGB 灯线不接**，包好。
4. **共地必须做**，否则读数全乱。
5. **风扇不要压在板子上**，金属框会短路。
6. 电源**限流设 0.3 A**，万一短路不会烧东西。

# 十一、附：本项目对风扇的电平要求（给顾问判断用）

| 参数 | 本设计的输出 | 4 线风扇的典型要求 | 是否满足 |
|---|---|---|---|
| PWM 频率 | **24.414 kHz** | 21–28 kHz（Intel 4 线规范） | ✅ |
| PWM 电平 | **3.3 V LVCMOS** | `V_IH` 通常 ≥2.0 V（部分 5 V 风扇要 3.5 V+） | 多数满足 |
| PWM 分辨率 | 12 bit（0–1000 步） | 无要求 | ✅ |
| TACH 电平 | 3.3 V 开漏输入，需外部上拉 | 开漏，需上拉 | ✅（需加 4.7 kΩ） |
| TACH 脉冲 | 按 **2 脉冲/转** 设计 | 标准就是 2 | ✅ |

> 如果 3.3 V 驱不动蓝线（表现为"改占空比转速不变"），两种补救：
> ① 用一颗 AO3400A 做开漏下拉（漏极接蓝线、源极接 GND、栅极经 100 Ω 接 B16）——**逻辑会反相，需改代码**
> ② 用 74LVC1T45 / 74AHCT1G125 做电平转换——不反相，最干净

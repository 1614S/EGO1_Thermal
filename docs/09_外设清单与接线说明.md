# 第一部分：这个项目要干什么

一套**芯片结温感知 + 动态热管理**的演示系统，跑在一块 FPGA 开发板上：

```
芯片自己发热  →  片内温度传感器测量  →  控制器算  →  驱动风扇散热  →  温度回落
        ↑                                                          ↓
        └────────────  同时用动态调频改变功耗，形成第二个控制维度  ──────┘
```

三个角色：

| 角色 | 用什么实现 | 现状 |
|---|---|---|
| **热源** | FPGA 内部故意跑的"自热负载"（大量寄存器翻转产生真实动态功耗） | ✅ 已实现，实测 950 mW，芯片自己升到 42 ℃ |
| **温度传感器** | FPGA 内部的 XADC 模块（测自己的结温，12 位，0.123 ℃/LSB） | ✅ 已实现，实测稳定读到 42.00–42.62 ℃ |
| **散热执行器** | **外接一个 4 线风扇**，由 FPGA 的 PWM 控制转速 | ⚠️ **PWM 信号已输出到引脚，但风扇还没接** |
| 环境温度传感器 | 外接 AM2302（温湿度，单总线） | ✅ **已接并验证**（3.7 V 供电、A13=3.53 V，3 s 刷新） |

**关键点：不需要外部加热片。** 芯片自己就是热源——这是本方案的巧妙之处，
也意味着外接的东西只有"风扇"和"可选的环境温度传感器"。

# 第四部分：需要外接什么（采购清单 + 接线）

## 4.1 必需项：4 线风扇 + 驱动电路

### 为什么必须是"4 线"

- **2 线**：只有电源，只能靠调压调速（不能用 PWM，会啸叫/启动不良）
- **3 线**：电源 + 转速反馈，**不能调速**
- **4 线**：电源 + GND + **PWM 调速输入** + **转速反馈输出** ← 本项目要的就是这个

### 买什么样的

| 参数 | 要求 | 说明 |
|---|---|---|
| 类型 | **4 线 PWM 风扇**（PC 机箱风扇/CPU 风扇都是 4 线） | 最常见的 12 V 80 mm 或 120 mm 机箱风扇即可 |
| 接线方式 | **电源常供 + 蓝线 PWM 调速**（不要斩 GND） | 见下方"先说一个弯路" |
| 电压 | 12 V（或 5 V） | 需要单独供电，**不能从 FPGA 的 3.3 V 抽** |
| 电流 | ≤0.3 A 最佳 | 太大要用更大的 MOS 管 |
| 转速反馈 | 必须带 tach 输出（第 3 根线） | 开漏输出，每转 2 个脉冲 |
| 尺寸 | 8–12 cm | 要能对着芯片近距离吹 |

### ⚠️ 先说一个弯路（重要，别按网上常见的"斩 GND"方案接）

网上很多"用 MOSFET 调风扇转速"的教程都是**斩风扇的 GND**。那个方法只适用于
**2 线/3 线风扇**；对 **4 线风扇是错的**，原因两条：

1. 4 线风扇内部有自己的换向控制芯片，**供电被 24 kHz 斩断会工作异常**（抖动、啸叫、启动不良）。
2. **致命**：tach（转速反馈）是开漏输出，以风扇自己的 GND 为参考。GND 在 24 kHz 上跳变，
   tach 波形跟着乱 → **测速直接失效**，堵转检测也就废了。

**4 线风扇的正确用法**：电源常供，用它的**蓝色 PWM 输入线**调速。

### 4 线风扇的线色（标准）

| 线色 | 功能 | 接哪里 |
|---|---|---|
| 黑 | GND | 12 V 电源负极 + FPGA 板 GND（共地） |
| 黄 | +12 V | 12 V 电源正极（**常供，不要斩**） |
| **蓝** | **PWM 调速输入** | **FPGA B16（J5 第 1 脚）** |
| 绿 | 转速反馈 tach（开漏） | FPGA A15（J5 第 3 脚）+ **4.7 kΩ 上拉到 3.3 V** |

### 接线（推荐方案）

```
   12V 电源正极 ────────────── 风扇黄线 (+12V)      ← 常供
   12V 电源负极 ──┬────────── 风扇黑线 (GND)
                  │
   FPGA 板 GND ───┘                                  ← 必须共地

   FPGA B16 (fan_pwm) ──────── 风扇蓝线 (PWM)         ← 直接接（3.3V 通常够）
                                                      若不识别，见下方"电平不够"

   风扇绿线 (TACH) ──┬──────── FPGA A15 (fan_tach)
                    │
                 [4.7 kΩ 上拉到 3.3V]                 ← 必须！开漏无上拉读不到
```

**要点逐条：**

1. **蓝色 PWM 线不能悬空**。4 线风扇的 PWM 输入在内部有上拉（到它自己的 5 V 或 3.3 V），
   悬空 = 恒高 = **100 % 占空比 = 风扇全速转**（不是停转）。所以"不接"等于"一直全速"。
2. 我们输出的 PWM 是 **24.414 kHz、3.3 V LVCMOS、12 位分辨率（0–1000 步）**，
   正好落在 4 线风扇推荐的 **21–28 kHz** 区间。
3. **tach 必须外部上拉**（4.7 kΩ 到 3.3 V）。板上没有内置上拉（XDC 只给 `dht_dq` 开了内部上拉）。
   浮空会读到一堆假转速，堵转检测会误报。
4. **必须共地**：风扇电源负极、FPGA 板 GND 连一起。不共地 = 读到乱码 + 可能打坏 IO。
5. 风扇电源**单独给**，不要从板子的 3.3 V 抽（会拉垮电压导致 FPGA 重启）。

### 电平不够怎么办（如果 3.3 V 驱不动蓝色线）

Intel 的 4 线风扇规范里 PWM 输入 `V_IH` 一般是 2.0 V 以上，**3.3 V 通常直接可用**。
如果接上发现"无论怎么改占空比，转速都不变"，说明这颗风扇要 5 V 电平：

| 方案 | 元件 | 说明 |
|---|---|---|
| **A. 直接连（首选）** | 无 | 先试这个，多数风扇 3.3 V 就认 |
| **B. 开漏下拉** | 1× AO3400A（源极接 GND，漏极接蓝线，栅极经 100 Ω 接 B16，栅极加 10 kΩ 下拉） | 蓝线内部已上拉到 5 V，MOS 拉低即可。**注意逻辑反相**：需要把 RTL 里的 PWM 取反 |
| **C. 电平转换芯片** | 74LVC1T45 或 74AHCT1G125 | 不反相、最干净，但要多一颗芯片 |

### 风往哪吹

**对着 FPGA 芯片本体**——板子正中那颗丝印 `XILINX ARTIX-7 XC7A35T` 的方形芯片（位号 U1）。
距离 **5–10 cm**，垂直吹。

> 注意：这是**裸封装、没有散热片**。所以风的效果有限（预期降 3–8 ℃，不是 20 ℃）。
> 先做个免费验证：拿任何能吹风的东西对着 U1 吹 30 秒，看结温掉多少。
> 掉 ≥3 ℃ 才值得接风扇；只掉 1 ℃ 就别折腾了。

## 4.2 可选项 A：AM2302（DHT22）温湿度传感器（测环境温度）

### 买什么样的

| 参数 | 要求 |
|---|---|
| 型号 | **AM2302（DHT22）**；旧型号 AM2301（DHT21）协议完全兼容，可直接替换（代码无需改） |
| 接口 | 单总线（1-Wire 风格，非标准 1-Wire） |
| 供电 | **3.5～5.5 V**（datasheet 值；**3.3 V 低于下限，不能用**） |
| 精度 | ±0.5 ℃ / ±2 %RH |
| 模块 vs 裸件 | 建议买"带 4.7 kΩ 上拉的三针模块"，省得自己焊（注意：模块的上拉是接到 **VDD** 的） |

### 接线（2026-11-21 实测确认）

```
   AM2302 VCC  ──── 3.7 V（实验室电源 CH1，可调；3.5～3.6 V 也行）
   AM2302 GND  ──── GND（必须与板子共地）
   AM2302 DATA ──── FPGA A13（J5 第 5 脚）
```

**关键约束：DATA 的高电平等于 VDD**（模块内部上拉接到 VDD，开漏输出），
而 XC7A35T 的 IO 绝对最大输入约 **3.6 V**。所以：

| VDD | DATA 高电平 | 是否安全 |
|---|---|---|
| **3.7 V（实测用这个）** | 实测 A13 = **3.53 V** | ✅ 安全 |
| 3.5 V（下限） | ≈3.5 V | ✅ 安全（余量很小） |
| **5.0 V** | 约 **5 V**，被 A13 钳位二极管压在 **3.7～3.8 V** | ❌ **超绝对最大值**，有灌流风险；必须加 BSS138/74LVC1T45 电平转换 |

> 2026-11-21 实测：5 V 供电时 A13 量到 **3.7～3.8 V**（5 V 经钳位二极管），
> 改 3.7 V 供电后降到 **3.53 V**，进入安全区。

- XDC 里 `dht_dq` 已开内部上拉（`PULLTYPE PULLUP`），模块自带外部上拉时不用再加；
- **时序必须留余量**（3.7 V 供电下 datasheet 的 5 V 时序不适用）：

| 参数 | 取值 | 说明 |
|---|---|---|
| 启动低电平 | **5 ms** | 器件允许 1–20 ms；原来 1.2 ms 在低压下会被判"没收到启动" |
| 响应超时 | **1 ms** | 原来 300 µs，低压下响应偏慢会被误判超时、事务被中止 |
| 轮询周期 | **3 s** | 器件要求 ≥2 s |

  症状与排查：早期版本表现为"上电读到一次，之后 `age` 恒 255、`TEXT` 不再刷新"，
  且**重载比特流后必须给传感器断电再上电才有读数**。用串口 `Z` 看错误计数
  （`E=`总错误、`C=`校验错）：当时 `E` 每周期 +1 而 `C` 恒 0 → 说明**完全没应答**（协议超时），
  不是校验失败。放宽上面三个参数后，重载比特流也不再需要给传感器断电；
- 诊断接口：`Z` 回复 `A=.. B=.. R=.. E=.. C=..`，`C` 增长表示"应答了但位解码错"；
- 系统采样周期是 100 ms，所以算法用"快慢双源"：XADC 每 100 ms 更新，
  AM2302 有新数据才刷新，并用"数据龄期"字段标出它有多旧；
- **不接也能跑**：不接时外部温度读 0，遥测里能看出来。

## 4.3 可选项 B：参考温度计（做 ±0.5 ℃ 标定用）

这是唯一"买了也不能自动接"的东西，因为需要人去读它、然后把读数敲进命令通道。

- 需要一支**独立的、可信的温度计**（0.1 ℃ 分辨率即可，比如电子体温计、DS18B20 模块 + 小屏）
- 用途：把温度计贴在 FPGA 芯片表面/旁边，读出真实温度，用串口命令告诉系统
  （`RT=<读数>` 记参考点，`Z` 回读系统原始值，两点之后算标定系数）
- 没有它，就**无法定量证明"20–60 ℃ 内偏差 ≤±0.5 ℃"**——这是赛题硬指标之一

## 4.4 明确不需要的东西

| 不需要 | 原因 |
|---|---|
| ❌ 加热片 / 加热电阻 / 热台 | **芯片自己就是热源**（内部负载实测 950 mW，能把结温抬到 42 ℃+） |
| ❌ 外部温度采集芯片（如 TMP102/DS18B20 接进 FPGA） | 片内 XADC 已经能测结温，精度 0.123 ℃ |
| ❌ 逻辑分析仪（可选） | 只有"切档真实耗时"这一项需要它，其余用串口就能验 |
| ❌ 示波器（可选） | 同上 |

# 第五部分：怎么验证接对了（软件侧）

所有验证都通过**一根 USB 线**（串口 115200 8N1）完成。

## 5.1 看遥测帧

```powershell
scripts\capture.bat -Port COM4 -Seconds 20
```

输出示例（真实数据）：

```
T= 42.32℃  Tset=50.0  TEXT=0.00  RH=0.0%  duty=0  gear=3  f=99.9MHz  P=950mW  state=0
```

字段含义：

| 字段 | 含义 | 接风扇后应观察到的变化 |
|---|---|---|
| `T` | 芯片结温 | 风扇转起来后应下降 |
| `Tset` | 目标温度 | 用命令 `S=45.0` 可改 |
| `TEXT` / `RH` | 外部温湿度 | 接 AM2302 后应变成真实环境值（否则是 0） |
| `duty` | 风扇 PWM 占空比 0–1000 | 温度高于设定值时应升高 |
| `gear` | 频率档位 0–4 | 自动调频会自己动 |
| `f` | 实测频率 | 24.9/49.9/74.9/99.9/149.9 MHz |
| `P` | 估算功耗 | 随档位/负载变 |
| `state` | 0=正常 1=警告 2=过温 3=严重 | 温度超 63/69/76 ℃ 会升级 |

## 5.2 命令通道（往串口敲 ASCII）

| 命令 | 作用 |
|---|---|
| `?` | 回一行状态：`T=42.3 A=25.0 S=50.0 D=0000 H=0060 G=3 ST=0`<br>（T=结温、A=AM2302 环境温度、S=设定值、D=风扇占空比、**H=加热占空比**、G=档位、ST=告警态） |
| `S=45.0` | 设目标温度（结温环） |
| **`SE=40.0`** | **设环境温度目标（加热环），默认 40.0 ℃** |
| `KP=200` / `KI=1.0` | 在线改结温环控制参数 |
| `RT=25.0` | 告诉系统"现在真实温度是 25 ℃"（标定用） |
| `Z` | 回读标定系数与原始码，以及 AM2302 错误计数 `E=`/`C=` |
| `CA=1.0` / `CB=0.5` | 直接写标定增益/偏置 |
| `R` | 清报警 |

# 第六部分：常见错误清单（照着排）

| 现象 | 最可能的原因 |
|---|---|
| 风扇完全不转，`duty` 却在变 | ① 蓝线没接（悬空其实是全速，若全不转则检查电源）② 没共地 ③ 风扇电源没给 |
| 风扇一直全速 | ① 蓝线悬空（内部上拉→100 %）② 蓝线接到了 3.3 V/GND 上 |
| `rpm` 一直是 0 或乱跳 | tach 没上拉（必须 4.7 kΩ 到 3.3 V） |
| `rpm` 是真实值的 2 倍/一半 | tach 脉冲数/转参数不同（代码按 2 脉冲/转） |
| 接上风扇后板子重启 | 风扇从板子 3.3 V 取电导致电压跌落 → 必须单独供电 |
| 转速不受控、始终一个速度 | 蓝线要 5 V 电平，3.3 V 驱不动 → 见「电平不够怎么办」 |
| AM2302 读 0 | ① 接错脚（要 A13/J5 第 5 脚）② 没上拉 ③ 传感器是 5 V 供电版本 |
| 串口完全没数据 | ① 比特流没下载（按了 PROG 键）② 波特率不是 115200 ③ 开关全 OFF 时是真实模式，温度可能读出异常值 |
| 温度一直 125 ℃ | 这是旧版本固件的问题（XADC 配置错误），当前固件已修复 |

# 第七部分：给"外接设备"的一句话总结

> 这块板子对外只有 **3 个待接信号 + 2 根电源线**：
> - `B16`（J5-1）风扇 PWM 输出（3.3 V，24.4 kHz）
> - `A15`（J5-3）风扇转速输入（开漏，需 4.7 kΩ 上拉）
> - `A13`（J5-5）AM2302 数据线（单总线，需 4.7 kΩ 上拉）
> - 风扇 12 V 电源 + 共地（板上有 GND 与 12V/5V/3V3 排针）
>
> 执行器只需要一个 **4 线 12 V 风扇 + 一个 4.7 kΩ 电阻**（tach 上拉）；
> 吹的对象是**板子正中那颗 FPGA 芯片**（它自己发热，最高约 1.6 W）。
> **不需要 MOSFET、不需要续流二极管**——4 线风扇用蓝线调速，电源常供。

## 0. 证据等级约定

| 标记 | 含义 |
|---|---|
| `【仿真】` | Icarus Verilog 14 + 虚拟热台，任何机器可复现 |
| `【仿真·代跑器件】` | Vivado 综合/实现，但器件是 `xc7z020clg400-1`（本机没装 Artix-7 库） |
| `【读代码】` | 逐行读 RTL 得到的事实 |
| `【实测】` | 板上测到的数据 —— **本项目目前全部缺失** |

> ⚠️ **报告里不能把 `【仿真·代跑器件】` 写成 `【实测】`**。35T 的正式 WNS/LUT
> 必须在装了 Artix-7 器件族的 Vivado 上重跑 `scripts\build.tcl`。

## 3. 还缺的证据（以及为什么缺）

| 缺项 | 为什么 | 怎么补 |
|---|---|---|
| ±0.5 ℃ 采温偏差 | 没有参考温度计；虚拟热台里注入了 +1.8 ℃ 偏置/0.998 增益，标定后应压到 ±0.5 ℃ 内 | 上板 + 恒温槽/参考温度计；或用虚拟热台做"标定有效性"演示 |
| 30 min 长跑 CSV | 需要板子 + 上位机 | `sw/host_logger.py`（在 `feat/waveform-tools` 分支上，需合并） |
| 端到端延迟实测 | 未单独测 | 加一个 TB：`sample_valid` → `seg7` 更新的时钟差 |
| 切档耗时 `SWITCH_MAX_US` | 计数器 `sw_max/100` 整除截断，仿真里恒 0 | 改 0.01 µs 单位；上板用 `F_MEAS` 复核 |
| DRP 真实器件行为 | 本机无 Artix-7 库；unisims 的 MMCM 在 iverilog 下不 lock | 上板读 `F_MEAS`（0x17）确认 4 档 = 1500 |
| τ / θ 实测 | 需要板子 | 三档阶跃 + 稳态热阻实验 |

## 4. 复跑方法

```bat
:: 全量（18 个 TB，含三档指标判分）
scripts\regress.bat full

:: 只跑快的模块级（约 2 分钟）
scripts\regress.bat

:: 看单项日志
```

依赖：Icarus Verilog（`D:\Apps\iverilog`，便携版，不写注册表）。

脚本结构不用改（每个 TB 一个 `-s <top>`）。

## 5. 报告里必须写的三句话

1. **虚拟热台不是"假数据"**：它替换的是器件接口层（XADC 的 DRP、AM2301 的单总线），
   下游算法/控制/遥测 RTL 一行不改；真实器件模式（`sw6=0`）走同一条数据链。
2. **三档指标是"模型在环"的结果**，不是真实热台实测；报告要写清"被控对象 = 2R2C 模型，
   参数见表"，并给不确定度讨论（τ 的拟合区间、θ 的 u(P) 主导项）。
3. **WNS/LUT 是代跑器件数据**（xc7z020clg400-1），35T 需重跑。
